## Simple Interest Calculator

A simple and easy-to-use Bash calculator designed to calculate simple interest based on the principal amount, annual rate of interest, and time period in years.

### Project Objective

This project demonstrates a basic financial calculation using Bash scripting. It is developed as an open-source project to support learning and collaboration.

### Inputs

The calculator accepts three inputs:

- **P (Principal):** Initial amount of money.
- **T (Time):** Time period in years.
- **R (Rate):** Annual rate of interest in percentage.

### Formula

Simple Interest = (P × T × R) / 100

### Example

Suppose:

- Principal = 5000
- Time = 2 years
- Rate = 5%

Calculation:

Simple Interest = (5000 × 2 × 5) / 100

**Result = 500**

### Output

The calculator displays the calculated simple interest.

### Technologies Used

- Bash scripting
- Linux command line
- Git and GitHub

### How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the script:

```bash
bash simple-interest.sh
```

4. Enter the principal, time period, and annual interest rate when prompted.
